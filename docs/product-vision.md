# Что мы вообще делаем

Три продукта на одном фундаменте. Порядок не случайный, это конвейер:
**анализ → действие → доказательство**.

> Записано со слов владельца. Раздел «Где мы сейчас» дописан отдельно и опирается
> на факты из работающей системы — чтобы замысел и состояние не смешивались.

---

## 1. CryptoSmith X Studio & API
### Public Market Infrastructure & Data Research

Фундаментальный слой рыночных данных и публичный шлюз для алгоритмических
трейдеров, исследователей и разработчиков. Studio & API не просто собирает
котировки — это полноценная исследовательская лаборатория.

* **Что делает.** Агрегирует, нормализует и хранит исторические данные с Kraken,
  Binance, WEEX, Hyperliquid и других бирж.
* **Особенности.** Автоматически обнаруживает новые торговые инструменты и
  отслеживает их жизненный цикл. Система строго контролирует качество потока,
  отличая отсутствие данных (gaps) от реальных нулевых значений, и позволяет
  сравнивать кросс-биржевые спреды.
* **Для кого.** Для тех, кому нужен чистый, бесперебойный API и надёжный фундамент
  для бэктестов и математического моделирования рынка.

## 2. CryptoSmith X Agent
### Autonomous Execution Environment

Персональный автоматизированный исполнитель. Изолированная среда, где ваша
торговая логика превращается в реальные действия на бирже без ручного
вмешательства.

* **Что делает.** Берёт на себя всю механику трейдинга. Пользователь подключает
  собственные API-ключи, конструирует стратегию, задаёт правила риск-менеджмента и
  делегирует управление Агенту.
* **Особенности.** Агент работает непрерывно в фоне. Он анализирует потоки из
  Studio, исполняет ордера на бессрочных фьючерсах, ведёт мониторинг открытых
  позиций, маржинального обеспечения и P&L в реальном времени.
* **Для кого.** Для трейдеров, которым нужен надёжный, безостановочный движок
  исполнения, исключающий эмоции и человеческий фактор.

## 3. CryptoSmith X Arena
### Verified Strategy Leaderboard & Telemetry

Публичный реестр торговых результатов и социальное ядро экосистемы. Место, где
эффективность алгоритмов доказывается криптографически верифицированными данными,
а не скриншотами.

* **Что делает.** Позволяет пользователям транслировать телеметрию работы своих
  Агентов и делиться торговыми стратегиями с сообществом.
* **Особенности.** Формирует прозрачные рейтинги на основе реальной статистики:
  подтверждённый P&L, максимальные просадки, винрейт и распределение прибыли по
  биржам. Все метрики опираются на реальные биржевые данные.
* **Для кого.** Для квантов и трейдеров, желающих публично подтвердить свой
  трек-рекорд, сравнить стратегию с другими на одинаковых рыночных фазах или найти
  прибыльные идеи для собственного Агента.

## Почему именно в этом порядке

Каждый следующий продукт не имеет смысла без предыдущего, и это не риторика, а
техническое ограничение.

**Arena нельзя построить на Agent, который не пишет журнал.** Рейтинг, который
нельзя перепроверить, — это скриншот с лишними шагами.

**Agent нельзя построить на данных, которым не веришь.** Стратегия, отобравшая
пару по спреду, которого в тот момент не было в записи, — это не стратегия.
Отсюда правило, которое проходит через весь код: **не выдумывать данные**. Пусто —
значит пусто; ноль — значит ноль; чего не было видно в ту минуту, того не было.

**Studio имеет смысл сама по себе.** Это единственный из трёх продуктов, который
живёт без остальных двух: чистая история перпетуалов по нескольким биржам с
честными пропусками — самостоятельный товар.

## Где мы сейчас

Состояние на 3 сентября 2026 года. Список правим по мере движения, а не
переписываем задним числом.

| | Состояние |
|---|---|
| **Studio — сбор** | Работает. 1479 торгуемых инструментов из 1482 известных, четыре биржи: Kraken Futures, WEEX Futures, Hyperliquid включены, Binance USD-M запланирована. Снапшоты, глубина, свечи, фандинг, обнаружение инструментов, производные таймфреймы 5…1440. |
| **Studio — качество** | Частично. Жизненный цикл инструментов и различение «нет данных / ноль» заложены в схему. Кросс-биржевые выборки опираются на реестр активов с алиасами. Слабое место — темп: WEEX не укладывается в свой интервал, см. заметку ниже. |
| **Studio — публичный API** | Нет. Есть админская консоль и OpenAPI-схема, публичного шлюза с ключами, квотами и тарифами не существует. |
| **Agent** | Прототип. Живут два экземпляра предыдущего поколения (`futures-live`, `futures-lukas-live`) на своих счетах и ключах, их телеметрия видна на входной странице. В новой системе есть места под Bots, Tenants и Clients, но ни одного бота ещё не зарегистрировано. Моделятор стратегий — макет: `/strategy-modeler`. |
| **Arena** | Нет. Ни одной строки. |

Ближайшее слабое место, известное и записанное: проход сбора глубины по WEEX
занимает около 8 минут при интервале в минуту, то есть глубина по этой бирже
снимается в разы реже, чем задумано. Глубина не восстанавливается задним числом —
подробности и общее правило в [recovery-playbook.md](recovery-playbook.md).
