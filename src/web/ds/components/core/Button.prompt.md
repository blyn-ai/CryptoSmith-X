Action button — violet `primary` by default; `gold` only for the one flagship action per view; `ghost` for secondary; `danger` for destructive; `quiet` for tertiary tinted.

```jsx
<Button>New strategy</Button>
<Button variant="ghost">Backtest</Button>
<Button variant="gold" size="lg">Go live</Button>
```

Sizes: sm (7×14) / md (11×22) / lg (13×26). Font is Space Grotesk 600 13px — never mono, never uppercase.
