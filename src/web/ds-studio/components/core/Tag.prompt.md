A categorical value in mono caps — instrument type, spread band, or the BEST winner.

```jsx
<Tag tone="perp">Perp</Tag>
<Tag tone="wide">Wide</Tag>
<Tag tone="best" title="Narrowest spread across the venues shown">Best</Tag>
<Tag tone="worst" title="Widest spread across the venues shown">Worst</Tag>
```

Only `best` and `worst` carry a ground, and both are washes so the word stays readable.
Mark both ends of a column or neither — a table that only ever praises tells you half of
what it knows. Never wrap a number in a Tag.
